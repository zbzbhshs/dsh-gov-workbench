平台办理规则

第一条　平台定位。综合政务智能工作台是 DeepSeek Harness 的运行界面，所有办理动作通过宿主进程内的 API 网关派发，与宿主共用同一套会话、模型、权限与统计能力，界面不做任何业务预设。

第二条　事项受理。提交申办后平台自动受理并分配事项编号。编号由宿主分配，全局唯一，不可转让。

第三条　权限与审批。权限档位决定沙箱范围与审批策略。凡涉及目录外写入、外部命令等敏感操作，平台会弹出审批事项；未获批准的操作不会执行，且全程留痕。

第四条　全程留痕。办理过程的每一步（轮次、步数、模型调用、工具调用、待办变更）都会写入会话日志，「运行轨迹」栏目实时展示，「卷宗档案」栏目可导出归档。

第五条　统计口径。界面统计严格取自宿主投影：轮次与步数、模型耗时、工具耗时、首 token 延迟、解码耗时与 token 数来自 sessionStats 投影；输入、输出与缓存 token 来自 tokenUsage 投影。平台不估算、不编造任何统计值。

第六条　数据安全。平台仅监听本机回环地址，所有接口均做来源校验与配对令牌校验，跨源请求一律拒绝。运行配置保存在 $DSH_HOME/gov-workbench.json，界面偏好保存在浏览器本地。

第七条　便民服务。首页提供常用通道与办理须知；「重要通知」栏滚动提示平台状态；便民提示飘窗可拖动、可关闭。
